1

Ten tu cuenta de Claude con plan Pro

Claude Code viene con el plan Pro (unos 20 dólares al mes). El plan gratis no lo incluye. Si ya pagas Pro o Max, salta al paso 2.

Ver planes de Claude →
2

Instala Claude Code

Escribe terminal en el buscador de tu computador y ábrela. Pega el comando de tu sistema y dale Enter. No muestra avance mientras descarga: espera a que termine.

WINDOWS
Windows PowerShell
irm https://claude.ai/install.ps1 | iex
MAC
Terminal
curl -fsSL https://claude.ai/install.sh | bash

Cuando termine, cierra la terminal y vuelve a abrirla. Los comandos son los de la página oficial de instalación. ¿Prefieres sin terminal? La app de Claude para el computador trae Claude Code en la pestaña Code.

3

Escribe claude e inicia sesión

Crea una carpeta en Documentos llamada mi-web. Luego, en la terminal:

WINDOWS
Windows PowerShell
cd Documentos\mi-web
claude
MAC
Terminal
cd ~/Documents/mi-web
claude

La primera vez te abre el navegador para entrar con tu cuenta de Claude. Entras, vuelves a la terminal y ya está Claude Code esperando tu mensaje. Si te pide permiso para crear archivos o instalar algo, acéptalo: así trabaja.

4

Instala Claude SEO

Dentro de Claude Code, pega estas líneas una por una y dale Enter después de cada una:

Claude Code
/plugin marketplace add AgriciDaniel/claude-seo
Claude Code
/plugin install claude-seo@agricidaniel-claude-seo
Claude Code
/seo setup

La última deja listo el navegador que usan los agentes para visitar tu página. Si te dice que falta Python, escríbele a Claude Code instálame Python y vuelve a correr /seo setup. Los comandos son los del repositorio oficial del plugin.

5

Audita tu página

Cambia la dirección por la tuya y pégalo en Claude Code:

Claude Code
/seo audit https://tupagina.com

El plugin detecta qué tipo de página es (tienda, servicio, negocio local…) y manda a sus agentes en paralelo. Revisan, entre otras cosas:

📝
Tu contenido: si explica bien qué haces y si Google lo considera confiable.
⚙️
Tu configuración: velocidad, títulos, imágenes, el mapa del sitio y los datos que lee Google.
🤖
La búsqueda con IA: si ChatGPT o los resúmenes con IA de Google te pueden encontrar y citar.
6

Lee tu lista de arreglos

Te entrega un informe con una nota general, los problemas críticos, las advertencias y lo que ya está bien. Empieza siempre por los críticos.

¿No sabes cómo arreglar algo? Pídeselo en palabras:

Claude Code
Explícame cómo arreglar cada problema crítico del informe, paso a paso, en [WordPress / Wix / Shopify / mi página hecha a mano]. Empieza por el que más me ayuda a salir en Google.
7

Tres comandos que te van a servir

/seo geoRevisa si las búsquedas con IA (ChatGPT, resúmenes de Google) te encuentran.
/seo localPara negocios locales: tu perfil de Google y tus reseñas.
/seo pageAnaliza a fondo una sola página, por ejemplo la de tu servicio principal.

Siempre con tu dirección al final, por ejemplo /seo geo https://tupagina.com.

Preguntas frecuentes

¿Es gratis?

El plugin sí. Lo que pagas es Claude Pro, unos 20 dólares al mes.

¿De verdad voy a salir 10 veces más en Google?

El plugin te dice qué arreglar y en qué orden. El resultado depende de que hagas los arreglos. Si tu página tiene problemas básicos, la mejora se nota rápido.

¿Sirve para páginas hechas en Wix, WordPress o Shopify?

Sí. Audita cualquier página pública, sin importar con qué esté hecha.

¿Puedo auditar la página de mi competencia?

Sí, cualquier página pública. Es una buena forma de ver qué están haciendo mejor que tú.
