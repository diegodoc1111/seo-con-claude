# Claude SEO: audita tu página para salir en Google (guía en español)

Guía gratis de [@soydiegoosorio](https://instagram.com/soydiegoosorio) para instalar el plugin **Claude SEO** en Claude Code y auditar tu página web: contenido, configuración y búsqueda con IA, con una lista de arreglos por prioridad.

**Página:** https://diegodoc1111.github.io/seo-con-claude/

El plugin es de AgriciDaniel: https://github.com/AgriciDaniel/claude-seo (licencia MIT). Esta guía solo explica cómo usarlo.

## Fuentes verificadas (4-nov-2026)
- Repositorio oficial (26,7 mil estrellas, MIT; instalación con `/plugin marketplace add AgriciDaniel/claude-seo`, `/plugin install claude-seo@agricidaniel-claude-seo` y `/seo setup`; `/seo audit`, `/seo geo`, `/seo local`, `/seo page`; auditoría de 10 a 15 minutos; sin llaves): https://github.com/AgriciDaniel/claude-seo
- Instalación de Claude Code: https://code.claude.com/docs/en/setup
